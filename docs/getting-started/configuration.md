## Tailwind CSS

This project uses Tailwind CSS for styling. You can configure it by editing the `tailwind.config.js` file.

The typography plugin is pre-installed to provide beautiful default styles for Markdown content.

## Next.js Config

The main Next.js configuration is located in `next.config.js`. You can modify settings like redirects, headers, and environment variables here.
